Supplementary Figure. Counterfactual language grounding across manipulation stages (stack_blocks_two, with click_bell as an offline reference).

(A) Schematic (no data): in stack_blocks_two the same scene is paired with the original instruction (grasp red first, stack green on red) or with the role-exchanged instruction (grasp green first, stack red on green); the referent must be re-assigned at Stage 1 and at Stage 2.

(B) OFFLINE SCORER-LEVEL results (no rollouts), held-out scenes of the referent scorer: accuracy on the original referent, accuracy on the counterfactual referent (instruction naming the other object, same scene), and the fraction of scene pairs in which both swapped referents are correct. Grey: scorer trained without counterfactual pairs; light blue: counterfactual-paired scorer trained on the same data; dark blue: frozen counterfactual-paired scorer (additionally trained on randomized-domain frames). n = 104 original / 80 counterfactual scenes (click_bell) and 345 / 30 (stack_blocks_two) for the matched-data scorers. Blank-/shuffled-instruction probes exist only for the earlier frozen scorers on original-referent frames and are not shown.

(C) NATIVE FRESH-SEED rollouts (Clean seeds 8100000+, Randomized seeds 8600000+, n = 20 episodes per bar, same seed sets for both models) with the role-exchanged instruction: COUNTERFACTUAL-GOAL COMPLETION, i.e. the exchanged goal (red block on green block) reached at the end of the episode (judged on final block poses with the tolerances of the environment's success check; privileged, analysis only). Previous frozen model vs updated model (stage-conditioned subgoal scorer + instruction-conditioned progress head). Error bars: Wilson 95% intervals.

(D) STANDARD TASK SUCCESS (environment success flag, original instruction) versus COUNTERFACTUAL-GOAL COMPLETION (role-exchanged instruction), same fresh seeds and n = 20 per bar. Counterfactual-goal completion rises (Clean 2 -> 13, Randomized 0 -> 6 of 20) while standard task success changes little and is not higher in Clean (19 -> 16; Randomized 12 -> 13); the Clean standard-success cells of the two models were run on non-identical seed sets (invalid scenes skipped differently), the standard-success differences have overlapping Wilson intervals, whereas the Clean counterfactual-goal intervals (2/20 vs 13/20) do not overlap. Only (C) and (D) are native rollouts; only (B) is offline.
